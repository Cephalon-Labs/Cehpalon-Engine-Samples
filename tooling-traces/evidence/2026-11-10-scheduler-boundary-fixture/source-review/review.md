## Exact hook semantics

[Scheduler trace declarations](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/include/trace/events/sched.h#L882) declare one bool for each hook: entry's `preempt` and exit's `is_switch`. The [DECLARE_TRACE bridge](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/include/trace/bpf_probe.h#L120) forms the actual raw names `sched_entry_tp` / `sched_exit_tp`. Retained pinned BTF has both callback typedefs and `(void *data, bool)` prototypes; the hidden data parameter is callback plumbing. Raw context argument 0 is the bool, never a task pointer. Require exact 0 or 1 in captured output, without coercing unknown integers to truthy.

At [core.c:6817](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/core.c#L6817), entry compares the mode specifically to SM_PREEMPT. Entry false is therefore not a general voluntary/blocking oracle: the source modes also include SM_NONE, SM_RTLOCK_WAIT and SM_IDLE. Do not substitute the broader debug variable initialized from mode > SM_NONE at6808.

At core.c6903 the saved invocation computes `prev != next`. The true branch emits sched_switch at6941 and calls context_switch at6944; the exit hook at6950 runs after that call returns. The [finish_task_switch explanation](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/core.c#L5163) states that saved task locals/stack are restored and the task may have moved CPU. Consequently an incoming task's exit belongs to its own earlier scheduler invocation. An outgoing entry and the next exit on the same CPU cannot be paired merely because they are adjacent.

Exit false is the source oracle that this invocation selected prev == next and omitted its context_switch branch. It does not establish uninterrupted physical CPU service: interrupt work and timestamp limitations remain outside the raw bool's meaning. Entry/exit helper timestamps still describe callback software points and cannot certify exact register-switch, physical off-CPU or runqueue duration.

## Prefix, newborn and terminal cases

A preexisting held actor may resume from an invocation entered before attachment or enrollment. Its first observed exit is a left-censored prefix. An unmatched prefix exit(true) must not be relabelled as newborn solely for lacking an entry.

A dynamically admitted child whose owned birth is observed before its first wake can reach [schedule_tail:5280](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/core.c#L5258). That path emits exit(true) before preempt_enable, without a prior entry belonging to the new child. Distinguish this proven newborn case from an initial seeded actor. Kernel current-task availability does not imply authority: establish the child through the existing authenticated-parent birth/generation contract before it can emit a boundary record. Do not assume it inherits the leader's task-storage cookie.

[do_task_dead:6953-6966](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/core.c#L6953) calls __schedule(SM_NONE) and never returns. A terminal entry(false) can remain open until the generation is freed. If the declared hook scope extends past process-exit retirement through free, classify this as a terminal open invocation using lifecycle evidence; it is not automatically lost data. If implementation suppresses retired generations, declare the earlier boundary-coverage cutoff explicitly. Do not require every valid entry to have an exit at process death or capture shutdown.

## No-switch runtime control

The [sched_yield syscall](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/syscalls.c#L1357) invokes the class yield callback then schedule(), and returns zero. [Fair-class yield](https://github.com/microsoft/WSL2-Linux-Kernel/blob/d504d40ab83839cb61942a812a99d183c42227b9/kernel/sched/fair.c#L9267) returns early when only one runnable task exists; otherwise it changes scheduler state before selection. Neither syscall success nor process affinity proves prev == next. Other host tasks and wakeups remain uncontrolled on shared WSL.

Use a fixed, predeclared bounded set of yields as runtime opportunities, preserving all entry/exit results. An observed matched exit(false) is actual no-switch coverage. If none occurs, record `runtime_no_switch_observed=false` and leave that native coverage unestablished. Do not loop until false, choose favorable cases, alter priorities or claim CPU isolation. Offline strict false-case fixtures can test the decoder without falsely replacing native evidence. A requirement that the finite native lane must demonstrate false remains an acceptance gate that may remain incomplete, not permission for an unchanged favorable rerun.

## Minimal readiness and analysis gates

1. Freeze exact hook name allowlist and raw bool ABI; retain actual program bytes, helper/ownership order, source/binary/host/BTF receipts and per-program recursion counters. Source/BTF map visibility does not prove attachment. Fail and retain a load/open rejection before uncontrolled work; no fentry or unrestricted tracing fallback.
2. Attach both boundary hooks before the controlled work, with separate owned birth/exit/free controls already armed. Root is the sole native operator. Use the existing held pidfd/current cookie and private generation/birth identity checks before task-field reads or output. Gate-closed nonmember controls must leave output/counters unchanged. Bound all generations and records before launch.
3. Preserve event kind, strict bool, owned execution/generation/local/native identity, emitter CPU, a per-generation event ordinal and raw ledger order. Logical pairing uses the generation's pending invocation, independent of CPU and independently of numerical timestamp sort. A second entry while one is pending needs explicit anomalous/unknown treatment; never overwrite and silently fabricate a pair.
4. Preserve unpaired initial prefix, lifecycle-proven newborn exit, no-switch false, migrated true pair, terminal open entry, and capture-end open entry separately. Late/duplicate/foreign/reused-generation events must fail a gate or remain unassigned. Do not join across execution IDs or retired/reused task identity.
5. Keep perpoint reference brackets when an actor oracle truly contains the callbacks. Do not transfer the prior gettid fixture's observed numerical envelopes to these hooks or to historical Roslyn. All fast-clock reversals and numerical bracket escapes remain outcomes, with zero loss/complete accounting separately enforced.
6. Include offline counterexamples for CPU-only mispairing (A entry onCPU0, B exit onCPU0, then A exit onCPU1), newborn versus seeded prefix, false exit, terminal entry, duplicate/nested entry, missing endpoint, invalid bool, stale/reused generation, capacity loss and cleanup. These fixtures establish parser behavior, without runtime or physical-duration qualification.
