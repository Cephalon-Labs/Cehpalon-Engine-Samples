# ADR0027 B1 disabled-FD permission/ABI preflight

Declared 2026-11-02 before perf_event_open. This is not a capture or positive actor conformance attempt. Exact executing source/command hashes will be frozen in b1-freeze.json before invocation.

Use ordinary WSL Python for offline checks. For B1 only, invoke the frozen preflight through existing wsl --user root, no permission/global tracing writes. Verify x86_64 ABI, current online topology (expected 0-19, maximum32), exact eight live-format hashes/IDs and input plan. Open exactly one sched_switch tracepoint FD on first online CPU with pid=-1/group=-1/CLOEXEC, disabled=1, period1, TID|TIME|CPU|RAW, sample_id_all/use_clockid CLOCK_MONOTONIC, no inheritance/kernel exclusion/callchains/task/mmap/comm sideband, read_format TIME_ENABLED|TIME_RUNNING|ID|LOST. Record requested attr bytes, ABI size and syscall results. No mmap, filter, ioctl ENABLE, actor, child workload, sampling or retry/fallback attrs in B1.

On success read the disabled FD once, retain all exact returned bytes and expected tuple interpretation including independent LOST; fcntl may read close-on-exec state, no live attr-readback claim. Require supported exact read layout then close the owned FD and verify closure. On failure retain errno and leave permission/LOST gates failed/unknown. On success those limited gates alone become observed; all actual filter/mmap/delivery/clock/loss/cleanup actor gates remain untested. Stop after B1 either way. A separate frozen B2 declaration is required for target launch and collection. No favorable unchanged attempt repeats. Retain stdout/stderr/exit and all source versions; maximum process deadline30seconds, no overwrite of outputs.
