# ADR0028 - Owned task-attached syscall PID mapping

Date: 2026-11-02 (Asia/Bangkok). Status: accepted bounded implementation/conformance preparation; actual invocation requires frozen source/protocol. Engine #20; #3 remains Blocked.

ADR0027's disabled scheduler FD succeeds, but global scheduler-payload TIDs are not mapped to owned namespace-relative actor leases. Exact matching kernel source supports a bounded candidate: perf_event_open with pid=leased local nativeTID,cpu=-1 resolves that task in the caller's PID namespace, and syscall tracepoint delivery is task-scoped. One controlled gettid event can carry the known local task in the perf header and current->pid/global TID in raw common_pid. This is a proposed identity bootstrap, not scheduler recording or established mapping.

Stage A allows source development/offline tests and read-only exact syscalls:sys_enter_gettid format, existing libatomic/Python image, resource/topology/namespace inventory. Do not install, change permissions/mounts/sysctl/global tracefs controls, enter/create namespaces or use alternate host traces. No raw_syscalls fallback: the syscall-specific zero-argument event avoids retaining six unused argument-register fields. Unavailable ABI/library/namespace/permission stays failed/unknown.

Stage A dependency preparation amendment, before acquisition: standard library probes found no libatomic. A private artifact may be downloaded from the official Ubuntu archive and extracted only beneath the new wave's ignored `.local` directory, with retained signed-index/checksum/package/library/license provenance. No package-manager installation, host files/loader cache or configuration writes. Require verified archive index signature, package SHA/architecture/version and exact ELF/library hash plus acquire/release export/self-test validation before any actor/perf FD. The actual tool must take an explicit pinned absolute library path; no automatic search/download/fallback during invocation. This supplies the same required atomic semantics and does not relax a gate.

Before any ordinary actor/perf FD launch, root freezes exact source/import/binary hashes, actor protocol, attributes/ABI, resource bounds, raw output directory and command. Use one fixed ordinary UID1000 child with process-local credential drop, retained ready/final barriers, UID/GID/starttime/image/PID+time namespace leases and owned child cleanup. Root is collector only. FD attaches to the checked local nativeTID, opens disabled, requests CLOCK_MONOTONIC TID/TIME/CPU/RAW and read_format23/CLOEXEC with no sidebands/callchains/inheritance. One forward ring uses actual acquire/release atomic head/tail access on the declared platform/library; no unverified memory-order fallback.

After validation, enable then release the actor for exactly one explicit gettid syscall with declared zero unused arguments, bracketed by its monotonic markers. Actor reports return/marker data and waits at final barrier. Disable, drain and read exact counters, close owned resources, then release/join the child. Maximum one event FD and one data page plus metadata page; total invocation30seconds, active scope10seconds. Reject missing/extra/malformed/LOST/throttle records, nonzero lost, count not1, incomplete drain, ID/layout/clock/header/local-lease mismatch, boot/namespace/topology/image changes or cleanup uncertainty. Preserve every source/fixture/failed/partial attempt; no fallback or favorable unchanged repeat.

Success only establishes one same-execution owned actor mapping with its retained sample. It does not establish generic lossless collection, allCPU scheduler filters, remote wakeups, dynamic ThreadPool coverage, duration/GC/scheduler causality or a product improvement. A later complete scheduler collector requires separately frozen overflow-negative then positive conformance and each static actor's own mapping/lease; do not import this one actor into a future boot/execution. Root sole integrator/operator/remote writer, isolated features/ code worktree, bounded independent source review. Sync only #20 body via reviewed plan/readback, preserve #3 entire row, all metadata/dependencies/estimates/Planned gates/null hours and original benchmarks/Engine. No supported-Windows/provider/reference/production/release qualification.
