# Active dynamic scheduler fixture under ADR0030

Date 2026-11-06. Run only on the pinned WSL x86-64 release and BTF from ADR0030. Freeze source, executable entry points, namespace inode, CPU 0 and CPU 1, hook order, program templates and acceptance checks before the attempt. The root controller owns all descriptors and launches one ordinary UID/GID 1000 actor per case. Raw hooks receive transient guest arguments. Only controlled task data and fixed counters are retained. Keep kernel addresses in neither scheduler output nor shared verifier logs. No pinning, host setting changes or general event stream.

## Ordered cases

1. **Seed only.** Attach `sys_enter` to recognize native x86-64 gettid 186. Other syscalls exit before lookup. The typed current task is eligible only if the private task-storage map already holds the exact seeded cookie. Observe absent before seeding. After seeding by held actor pidfd, execute one unseeded controller gettid and verify the cookie is unchanged and the controller has no entry. The ordinary actor's declared marker changes its exact cookie to a fixed acknowledgement in kernel. Verify it from the independently opened alias. Close the hook, check zero recursion misses, delete the seed and reap the actor.
2. **Loss negative.** Use fresh maps and actor, repeat the seed handshake, close the syscall hook and arm the eight named lifecycle hooks. Reserve one logical publication slot. A fixed ordinary process fork must leave counts empty. Create exactly one ordinary worker after arming. Require real empty-pipe sleep, controlled cross-CPU wake, join, proc disappearance and a free-completed counter within two seconds of join. Require positive sink loss, one complete birth record and exact terminal reconciliation. This intentionally rejects completeness and measures the fixture's own publication capacity only.
3. **Positive.** Repeat the same fixed controls in a fresh session with 512 logical slots. Require zero lost publications and zero faults. The complete ledger must show birth before first wake and switch, confirmed interruptible switch-out before the blocked-read oracle, one `sched_waking` from CPU 0 to target CPU 1 inside the pipe write bracket, target `sched_wakeup` and switch-in on CPU 1 before read return, then exit, raw terminal switch-out and free. The wakeup callback can emit on either of the two CPUs. Require one unique owned worker identity throughout and match its BTF-mapped local TID to the actor's native TID.

The collector checks named raw link fdinfo and zero recursion misses on each owned program. A fixed BPF array stores records with monotonic timestamps and unique atomic ticket slots. The index need not define a global clock order. Terminal counters separate attempted publications, overflow, faults and completed frees. Confirm all unused slots are zero and read the entire ledger twice after detachment. At birth, require a typed acknowledged owner, CLONE_THREAD, same kernel TGID, local namespace inode, global and local TIDs, and cached task birth identity. The write-only userspace descriptor for private state is never read. Only a live argument that matches the stored pointer and birth marker can contribute later events. Free uses cached TIDs. The owned exec guard latches a fault before exec changes identity.

The blocked-read oracle retains syscall number, pipe FD, byte count, state, CPU and monotonic time only. The raw arguments containing addresses are discarded. Require the actor's stable identity, same zero-offset monotonic namespace, bounded controls, clean actor exit and all owned descriptors closed. Keep each attempt and its failure stage. Proceed in order only when the preceding case meets its gate. A correction after rejection requires an explicit reason, a new source freeze and a complete fixed ordered attempt.

The result is limited to this one synthetic worker and held-owner shape. No Roslyn or original benchmark is included. Capture readiness for Roslyn remains false.
