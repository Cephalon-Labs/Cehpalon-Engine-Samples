## Question and measurement boundaries

The existing Task.Delay(1) arm/resume markers include timer eligibility, managed callback dispatch and continuation dispatch. Add synthetic probes with exact same-trial publication identities so the managed callback-entry leg and completion-publication-to-observed-resume leg can be bounded separately. A managed timer callback entry is not the native timer-ready timestamp. QueueUserWorkItem returning true establishes accepted managed work, not OS ready-to-run time. Residual time and CLR suspension are not exclusive GC/scheduler causal shares.

Run four profiles sequentially in every fresh process: direct Task.Delay(1), one-shot System.Threading.Timer(1 ms) with RunContinuationsAsynchronously completion, the same timer with inline-eligible completion, and accepted QueueUserWorkItem with asynchronous completion. Register the await helper while its completion source is still incomplete before arming/queuing. Record before/after arm/queue call, managed callback entry, before/after TrySetResult, observed await resumption, callback completion and timer disposal. Await the callback's completion before reusing the trial state. Use a bounded ten-second per-trial wait; failed/partial data must persist.

Each numeric raw point stores QPC before/after optional marker emission, native/managed TID and ThreadPool endpoint counters. EventPipe markers use the existing receipt ledger, header identity, loss and QPC-slope validation. Match by process/capture/profile/trial/kind; retain duplicate/missing/ambiguous identities as invalid. Allow callbacks before arm/queue return and asynchronous resumption before the publisher's after-marker on another thread. An inline claim requires both matching callback native TID and a resumption bracket contained inside publication; same TID alone is not proof. Clamp lower bounds to zero where endpoint intervals race; never manufacture negative queue time.

For publication-to-observed-resume, use the interval endpoints to produce a conservative lower/upper bound; report the guaranteed post-publication window separately. Clip the union of process-local GC inner/envelope intervals to those windows. Retain unaccounted time as unknown, never kernel scheduler share. Report all individual trials, first calls, races, bounds, means/medians/min/max and nearest-rank p95. Do not filter outliers or select favorable executions.
