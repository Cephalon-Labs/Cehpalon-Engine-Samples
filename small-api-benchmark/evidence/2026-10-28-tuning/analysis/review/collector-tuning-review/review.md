# Indexed collector and native-layout controller source review

No remaining concrete finding in the reviewed source snapshots; exact SHA256/base revision are in review.json. This was read-only: the reviewer ran no build, timing trial or proof suite.

The driver stores immutable per-index observations using Interlocked.CompareExchange, rejects duplicate/out-of-range writes, retains faulted pending tasks, joins active requests, persists observed rows/accounting in finally, then rejects partial/failed phases. Completed-success tasks may be removed because their recording and ownership unwind are complete. Cap128, scheduled1s deadlines, writer-lane ordering, cancellation, status/body validation and raw8-field schema remain unchanged. Reference slots are preallocated; Observation objects still allocate. Abrupt process termination may lose the in-memory phase and must invalidate the attempt; managed exceptions preserve observed records where persistence remains available.

The original proposal included the entire new deferred gzip interval inside server allocation/CPU counters. That was corrected explicitly: request join, client-after snapshot, bounded10s final-server-metrics control request, then raw persistence. Metrics/control failures aggregate into phase failure and cannot bypass the raw flush. Client snapshots precede schedule origin and follow request join, excluding control/persistence. Approximate collector allocation, GC/pool counters and post-TLS-handshake timestamps have explicit boundaries. This correction changes the metrics window versus attempt02 and must be disclosed; it does not change request latency timestamps or acceptance thresholds.

The controller declares shared native SDK/app/cwd/output paths for both variants. Readiness stat/read retries only ENOENT/EAGAIN/ENODATA under the original start timestamp and60s deadline; no startup sample is dropped. Atomic ready publication is a functional robustness correction, not a stopwatch reset. Loaded runtime maps are captured after the counted first verified response; extra inherited runtime environment values are observed, not changed. Native location does not establish dedicated CPU/RAM or supported-Windows proof.

The retained2x2 location diagnostic remains descriptive; full30-launch p95 and all five paired performance observations still decide the unchanged budgets. Any improvement combines deployment/packaging/collector changes, not necessarily Engine code. The original attempt02 failures remain retained. No artificial CV floor, baseline penalty, rate reduction, outlier filtering or maturity promotion is authorized by this review; #3 stays Blocked.
